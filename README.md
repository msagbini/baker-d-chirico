# Baker D. Chirico – Website

A modern, responsive website for Baker D. Chirico, an iconic Australian artisan bakery. Built with HTML, CSS, and vanilla JavaScript.

## 🌟 Features

- Fully responsive design (mobile-first)
- Clean, minimal aesthetic inspired by the brand’s identity
- Interactive menu highlights
- Image gallery for the physical space
- Online ordering CTA
- Contact form (front-end demo)
- Smooth scrolling and animations
- Basic SEO meta tags

## 🚀 Getting Started

1. Clone the repository or download the files.
2. Open `index.html` in your browser to view the site locally.
3. Replace placeholder images with your own (see `images/` folder).
